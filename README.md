# The Rabbit Hole 🐇

A complete full-stack philosophy blog platform built from scratch during my internship — from database design to deployment.

🔗 **Live:** https://rabbit-hole-frontend-production.up.railway.app/
🎥 **Demo Post:** https://www.linkedin.com/posts/ramsha-abid-b8b753312_mern-fullstackdeveloper-reactjs-activity-7491944131682934784-Bvdg

## ✨ Features
- ⚛️ React frontend with dynamic routing, category filtering, and saved blogs
- 🔧 Node.js + Express REST API with MongoDB/Mongoose
- 👁️ Real-time view tracking and trending articles
- 🛠️ Full admin dashboard with CRUD for posts, categories, and comments
- 📧 Newsletter subscription system
- 📬 Contact form with backend validation
- 📱 Fully responsive UI

## 🛠️ Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB, Mongoose

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB

### Installation
\`\`\`bash
git clone https://github.com/ramshaabid445-del/rabbit-hole-blog.git
cd rabbit-hole-blog

# Backend
cd backend
npm install
npm start

# Frontend
cd ../frontend
npm install
npm run dev
\`\`\`
